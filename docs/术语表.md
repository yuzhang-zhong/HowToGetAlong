# 读懂数字与名词（术语表）

正文尽量用日常说法，但引用研究时免不了几个统计名词，法律条目也有几个专门制度。看不懂就查这张表；检索页里，把鼠标停在带虚线的词上（手机上点一下）也会弹出解释。

## 统计与研究设计

| 术语 | 意思 |
| --- | --- |
| d、g | 效应量，表示两组差距有多大。换算成「相当于几倍的常见波动幅度」：0.2 算小，0.5 中等，0.8 大 |
| r | 相关系数。两件事一起变的紧密程度，取值 -1 到 1：0.1 弱、0.3 中等、0.5 强。r=.28 读作「中等偏弱的关联」 |
| ρ | 希腊字母 rho，荟萃分析里常用的相关系数，读法同 r |
| OR | 比值比。两组「出事的可能性之比」。OR 1.5 = 高约五成。病例对照研究算出来的 OR 是「比值」，不是严格的「风险倍数」，转述别放大 |
| RR | 相对风险。同样一段时间里，做了某件事的那组出事的快慢，除以没做的那组 |
| HR | 风险比。追踪研究中两组出事速度之比，读法同 RR |
| 95% CI | 95% 置信区间。研究算出的数字总有误差，这是真实情况很可能落在的范围。倍数类的数字，范围跨过 1；加减类的数字，范围跨过 0，就说明差别可能只是碰巧，文中会写「不显著」 |
| 荟萃分析 | 把很多项研究凑到一起重新算出一个总的数字，也叫 meta 分析 |
| 网络荟萃 | 荟萃的升级版：能同时比较多套疗法谁更有效，不要求每两套都直接比过 |
| RCT | 随机对照试验。抽签一样把人分成两组，一组做一件事、一组不做，过后比结果。证明因果最有说服力的设计 |
| 队列 | 队列研究。挑一大群人跟踪很多年，记录谁出了事。能看出两件事一起出现，但不足以证明前者造成后者 |
| 病例对照 | 拿「出过事的人」和「没出事的类似的人」回头比，找哪里的经历不一样。适合研究罕见的事（如凶杀），但只能算出比值比，且容易有回忆偏差 |
| 交叉设计 | 每个被试都先后经历两种条件（顺序随机），自己跟自己比。样本小也较有说服力 |
| 观察性 | 研究者只记录、不安排谁做什么。数字要打点折看 |
| 横断 | 一个时间点上的一次性调查，看不了先后因果 |
| 日记法 | 让被试每天记录（通常 1–2 周），比一次性问卷更贴近日常 |
| 经验取样 / EMA | 日记法的加强版：一天多次、随机时点回答，捕捉当天的真实波动 |
| 混杂 | 有第三个因素同时牵动前因和后果，让两件事看起来像因果。爱吃菜的人往往也更爱运动，分不清是哪样在起作用 |
| 反向因果 | 因果方向弄反了：不是睡得多让人早死，是病重的人睡得多 |
| 发表偏倚 | 阴性结果不容易发表，荟萃里收集到的多是阳性，总效应会被高估 |
| 交叉验证 | 用模型自己的数据考自己（样本内分类）分数会虚高；交叉验证拿没见过的数据考，才是真本事 |
| 预注册 | 做实验前先把方案公开存档，防止事后挑好看的结果说 |
| 复制失败 | 别的研究团队用同样方法做不出同样结果。出现过的结论要打折看 |

## 关系与沟通术语

| 术语 | 意思 |
| --- | --- |
| 四骑士 | Gottman 归纳的四种最伤关系的冲突行为：批评、蔑视、防卫、石墙 |
| 蔑视 | 四骑士里预测力最强的：讥笑、嘲弄、翻白眼、居高临下的纠正 |
| 生理淹没 | flooding。吵架时心率飙升、肾上腺接管，讲不出道理也听不进话的状态 |
| 修复尝试 | 冲突中递台阶的动作：一句玩笑、递杯水、碰一下胳膊 |
| 永久性问题 | Gottman 的说法：吵赢也还会再来的分歧（作息、习惯），对应可解的「账单式问题」 |
| 主动-建构式回应 | 对方报好消息时的最佳姿势：热情＋追问。四种回应（主动/被动×建构/破坏）里最养关系的一种 |
| liking gap | 交谈后，双方都低估对方喜欢自己的程度，这个错位持续数月 |
| 共反刍 | 两个朋友反复重播同一个烦恼：友谊更亲密，抑郁焦虑也更高 |
| phubbing / technoference | 伴侣在场时低头刷手机、设备打断共处 |
| ghosting | 不告而别：不回复、不说明、直接消失 |
| MUM 效应 | 人们系统性回避传递坏消息（mum = 缄默） |
| we-talk | 冲突谈话里多用「我们」少用「你/我」的说话方式 |
| 要求—退缩 | 一方追着谈、一方关机的冲突循环，两人共建 |
| 投资模型 | 承诺 = 满意度 + 替代选择 + 投入量；解释「明知道不好却离不开」 |
| 伴侣响应性 | 感觉到伴侣真的看见、理解、支持自己，关系研究里核心的好东西 |
| PGD | 延长哀伤障碍：丧亲约一年后仍被想念吞没、功能受损，已入 ICD-11，可治 |

## 制度与法律

| 术语 | 意思 |
| --- | --- |
| 人身安全保护令 | 法院签发的命令：禁止家暴、禁止骚扰跟踪接触、可责令迁出住所。不需要先离婚先起诉 |
| 告诫书 | 情节较轻不予治安处罚时，公安对家暴加害人出具的书面警告，留证用 |
| 强制报告 | 密切接触未成年人的行业发现孩子疑似被侵害，必须立即报公安的制度 |
| 意定监护 | 成年人在清醒时书面约定自己以后的监护人 |
| 离婚冷静期 | 协议离婚的 30 天反悔期＋30 天领证期；诉讼离婚不适用 |
| 法释〔2022〕17 号 | 最高法关于人身安全保护令的司法解释：把冻饿、经常性侮辱威胁跟踪骚扰也算进家暴，证明标准降为「较大可能性」 |
| 法释〔2024〕1 号 | 最高法涉彩礼纠纷规定：什么算彩礼、什么情况返还多少 |
| 条文号以新版为准 | 《治安管理处罚法》2025 年修订、2026-01-01 施行，旧第 42 条现为第 50 条；本书一律引新版 |
