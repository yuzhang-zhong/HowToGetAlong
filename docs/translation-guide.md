# 翻译指南

简体中文 `book/` 是本项目的内容底本。检索页的英文界面与 `README.en.md` 帮助读者浏览项目；它们不代表全书已有英文译本。当前检索页展示的条目正文和来源仍是中文。

## 目录结构

逐章翻译放在 `translations/<语言代码>/book/`，沿用原章节文件名和条目编号。例如：

```text
translations/
└── en/
    └── book/
        ├── 01-别让关系慢慢变淡.md
        └── 02-吵架别吵出事.md
```

在每个译文文件开头注明语言、中文源文件路径和对应的 Git commit，方便读者核对版本。

## 翻译时保留什么

- 保留章号、条目号、七个字段、证据等级和成本标签。不要为了让译文读起来更有力而改数字、结论或等级。
- 来源栏的论文标题、作者、年份、DOI、官方机构名称和链接按原文保留；可以在后面附译名。
- 法律与公共服务条目针对中国大陆。翻译时说明适用地区，不要替换成别国的法律建议。
- 对证据范围、样本、研究设计和外推风险的限定要一并翻译。遇到术语，优先使用该语言的通行说法，并在术语表说明选择。
- 有歧义或无法确认的句子先开 issue 讨论，不自行补充解释或新数字。

## 复核和提交

译文需要逐条对照中文底本，重点核对数字、否定词、适用对象、安全步骤、证据等级和链接。法律、安全及健康相关条目应由熟悉相关领域和目标语言的读者复核。AI 可以协助起草，不能代替来源核对与人工审阅。

提交 PR 时写明源文件 commit、覆盖的章节、复核者和未解决的术语。中文正文更新后，译文应标注待同步状态，直到复核完成。未经复核的译文不能标成正式版本。
