# 写作规范

本仓库每一条建议都必须按这套模具写。规范本身向《高性价比人生指南》的条目结构看齐，口径和分级为关系领域重新定义。改规范先改这里，再改已写条目。

## 一、条目格式

每条建议固定七个字段，一个不缺，顺序不换：

```markdown
### 5. 吵到心跳加速、说不出整句话时，叫暂停并约好半小时后回来
<!-- 成本标签: 难受=少 时间=少 毅力=些 收益=大 口径=关系质量 -->
- 成本：要说清花掉什么。关系条目的成本主要是「难受」（开口的心理门槛），连带的时间、金钱如实写。
- 说人话：把研究结论翻译成日常说法，只用「收益」栏已写到的内容，不添新数字。
- 收益：照抄来源里的关键数字、人群、研究设计，一个不改。没有数字就写「无具体数字」并描述方向。
- 证据等级：A / B / C
- 来源：作者 (年份). 标题. 期刊. 链接（DOI 或官方页面）
- 备注：适用人群、争议、例外、外推风险都写在这里。没有例外也写「无已知例外」，逼自己想一遍。
```

**标题一律动词开头**，写清是「做什么」还是「别做什么」（反面清单章的祛魅条目可以引流行说法开头，但后半句要落到动词句式）。章标题说这一章想防住什么（如「别让关系慢慢变淡」），不代表每条都是「别」。

## 二、成本标签

每条标题下带一行 HTML 注释，给机器读：`难受 0/少/中/多、时间 0/少/中/多、毅力 否/些/是、收益 大/中/小、口径 <七类之一>`。

- **难受**是关系领域的主成本：开口、示好、认错的心理门槛。0=不用开口，少=普通人一咬牙能做，中=需要鼓几次劲或先做铺垫，多=需要多次鼓劲或外部支持。
- **时间**：0=不占时间，少/中/多照常理。**毅力**照原书口径。钱不进标签，写在「成本」栏文字里（约会活动、咨询费等）。

## 三、证据等级

| 等级 | 含义 |
| --- | --- |
| A | 有具体数字可查，出处是荟萃分析、大型队列或随机分组的试验（RCT）；法律条目引到法条或官方文件原文 |
| B | 有研究支持，但说不出确切数字；或只有小样本、单独一项研究、观察性/相关设计撑着 |
| C | 作者的经验或公认做法，没有直接研究文献 |

关系领域比医学领域 A 级少得多，**如实反映，不硬凑**。观察性研究（Gottman 系列等）哪怕名气再大，没有确切数字或没有交叉验证的，最多 B，并在备注里写明设计局限（样本内分类、无交叉验证、纯相关）。凡流行说法追溯不到一手文献的（如「69% 的问题无解」），如实标 C。

有反方证据或复现失败的，备注里写「争议」并列出。没核实完的标「TODO 待核实」，不当结论用。

## 四、口径（换回什么）

关系条目换回的东西分七类，**各类之间不折算、不排序**：

1. **关系质量**：关系满意度、冲突频率与烈度、关系存续
2. **心理健康**：孤独感、抑郁焦虑指标、主观幸福感
3. **时间精力**：少内耗、少为同一段关系反复消耗
4. **人身安全**：防家暴、防纠缠、防霸凌升级
5. **人身自由**：保住行动与决定权（监护、婚姻、程序上的自由）
6. **寿命**：社会连接对死亡率的效应（第 1 章定调用）
7. **金钱**：借钱、纠纷、随礼、咨询花费

「社会连接让死亡风险低一半」和「道歉让关系满意度高一点」不在一把尺子上，各排各的。

## 五、受益人分档

一条建议的好处落在谁身上，按从高到低：① **你自己**；② **伴侣和直系亲属**；③ **朋友、同事和其他亲属**；④ **陌生人与社会**。第 ④ 档的好处和风险一起写。关系条目多数落在 ①②，少数（如「被求助时答应」）写清对方视角。

## 六、收益量级

- 换**关系质量 / 心理健康**：效应量 d≥0.5 或 RR/OR≥1.5 为大，d 0.2–0.5 为中，<0.2 或只量到中间指标为小；观察性研究按其预测强度酌降
- 换**人身安全**：避免死亡或重伤为大，避免纠缠升级为中，避免纠纷为小
- 换**寿命 / 金钱 / 时间精力**：照《高性价比人生指南》的界线

**性价比档的算法**（权威实现在检索页 [index.html](../index.html) 顶部的 `COST_W` 和 `tierRule` 常量，引用/改动以那边为准）：

1. 成本标签换算成分值：难受 0/少/中/多 = 0/1/2/3；时间 0/少/中/多 = 0/1/2/3；毅力 否/些/是 = 0/1/2。**成本分 = 三项相加**（0–8）。
2. 收益分：大=3、中=2、小=1。
3. 落档：收益大且成本分为 0 = **极高**；收益大且成本分 ≤2，或收益中且成本分为 0 = **高**；其余 = **一般**。
4. **第 4 章（安全）不计算档位**：按危险信号与行动优先级排序，检索页显示「安全优先」徽章。

「一般」不等于不该做——全书的条目都是建议做的，只是那笔花销得自己掂量。

## 七、章内排序

条目按性价比从高到低排：几乎零成本、防住大损失或换来大好处的在前。**安全章例外**：按危险信号的识别价值和行动优先级排，最危险、最紧急的在前。

## 八、写作纪律

1. **数字照抄条目来源**。置信区间、人群、年份一并保留；HR、RR、OR、d 旁边就地翻成「高约/低约百分之几」，原值不删。来源里没有的数字、机制解读一律不加。
2. **口语化**。按没受过专业训练的成年人能一遍读懂来写，专业名词当场用日常话解释一句。
3. **语气克制**，不说教，不用感叹号，简体中文。不劝分、不劝和、不站队：把依据摆出来，决定留给读者。
4. **不给人贴诊断**。「自恋型人格」「煤气灯」「有毒」这类流行标签不作为判断输出，正文只用行为描述（「反复否认你亲历的事」而不是「他在煤气灯你」）。
5. **只引一手来源**：期刊论文附 DOI 或 PubMed 链接，或官方机构原文。二手转述一律不进「来源」栏；官方不公开的，引署名原创新闻报道并在备注写明「只有媒体报道」。
6. **外推要说**。研究在陌生人身上做的，不得写成「对伴侣同样有效」，备注必须写明样本局限。
7. **政策与法律数字带截至日期**，提醒读者自查官方渠道。
8. **每写完一条，登记进 [核实记录](核实记录/)**：研究全称、链接、设计、关键数字、未核到的细节。先核实后写正文，查不到就降级或放弃这条。

## 九、与《高性价比人生指南》的分工

它管个人的账（寿命、金钱、时间、自由），本书管关系的账。交叉引用格式：「见《高性价比人生指南》第 8 节（借条和担保）」附仓库链接。指向、不复制正文。
