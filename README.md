# 高性价比关系指南

讲怎么把关系处好：怎么回应、怎么感谢、怎么开口说难说的话、架怎么吵不伤人。讲怎么交新朋友、怎么不孤独、职场和家人怎么处、性与亲密怎么谈。也讲什么时候该撤：控制、家暴、纠缠的红线怎么认，撤的时候怎么用法律保护自己。18 章 274 条建议，每条写明花掉什么、换回什么、证据有多硬，来源只引期刊论文和官方文件，流行说法查无实据的如实标 C、写进反面清单。

不用全做：这是按性价比和优先级排好的备选单，不是任务清单——挑走一两条就算数。

**种子版声明**：全部条目经三轮 AI 文献检索核实（[核实记录](docs/核实记录/)），**尚未人工复核原文全文**。引用前请先核对来源；标注「待人工复核」的条目尤其注意。

## 在线检索页

仓库根目录的 `index.html` 是纯静态检索页：按关键词、章节、证据等级、收益量级、口径、三项成本筛选，带性价比档（极高/高/一般）和安全章优先徽章；条目之间的「第 X 章第 Y 条」交叉引用可以点开就地预览。数据直接取自 `book/`，正文一改页面跟着变。

- **在线用**：开 GitHub Pages（仓库 Settings → Pages → Deploy from a branch → main → `/`）即可访问。
- **本地跑**：仓库目录执行 `python -m http.server 8000`，浏览器开 `http://localhost:8000/`。直接双击本地文件会空白（浏览器不允许网页读本地文件），那种场景用下面的离线版。
- **离线单文件**：`node tools/offline/build.mjs` 生成 `dist/HowToGetAlong.html`，整本书连同检索都在一个文件里，双击就开、微信可传。

术语看不懂查[术语表](docs/术语表.md)。

## 让 AI 照书回答（skill）

仓库带一个中文 skill：[skills/relationship-guide](skills/relationship-guide/)。装上后直接问「朋友借钱不还怎么开口」「吵架吵到失控怎么办」「他这样算不算家暴」，它会先把相关条目查出来，再按书的排序方式回答，注明出自第几章第几条；查不到就说查不到，不自己编数字。危机情况（家暴进行中、自杀念头、未成年人侵害）先给资源再分析。

- **Claude Code / Codex**：装法见 [skill 说明](skills/relationship-guide/README.md)
- **对话式助手（Muse 等）**：把 `book/` 各章作为知识库上传 + 把 SKILL.md 全文贴进系统提示词，同样见 skill 说明
- **只能填系统提示词的助手**：直接粘贴[纯提示词精选版](skills/relationship-guide/PROMPT-ONLY.md)，内含 30 条常用建议和安全章全部 30 条；未收录的问题会明确说明。

## 每条建议长这样

```markdown
### 1. 吵到心跳加速、说不出整句话时，叫暂停并约好半小时后回来
<!-- 成本标签: 难受=少 时间=少 毅力=些 收益=大 口径=关系质量 -->
- 成本：硬着头皮说「我需要停一下」。
- 说人话：吵到身体接管嘴巴的时候——心跳快、耳朵关、只剩想赢——……
- 收益：实验室研究：夫妻冲突对话中，一方的生理唤起水平与婚姻不满相关……
- 证据等级：B
- 来源：Levenson RW, Gottman JM (1983). Marital Interaction. JPSP. https://doi.org/10.1037/0022-3514.45.3.587
- 备注：关键纪律只有一条：走之前必须约好回来的时间，否则暂停变成冷暴力……
```

## 证据分级

| 等级 | 含义 |
| --- | --- |
| A | 有具体数字可查，出处是荟萃分析、大型队列或随机分组的试验（RCT）；法律条目引到法条或官方文件原文 |
| B | 有研究支持，但说不出确切数字；或只有小样本、单独一项研究、观察性/相关设计撑着 |
| C | 作者的经验或公认做法，没有直接研究文献 |

274 条中 A 级 126 条、B 级 122 条、C 级 26 条。关系领域比医学领域 A 级少——**如实反映，不硬凑**：观察性研究名气再大，没有确切数字或没交叉验证的最多 B；流行说法追溯不到一手文献的（如「69% 的夫妻问题无解」）如实标 C；复制失败的说法（如「手机摆在桌上就毁掉对话」）降级并注明。

条目写法、口径定义、成本标签、性价比档算法（权威实现在 index.html 的 `COST_W`/`tierRule`）、排序规则见 [写作规范](docs/写作规范.md)。争议条目在备注里列反方证据；没核实完的标「待人工复核」，不当结论用。

## 和《高性价比人生指南》的关系

[《高性价比人生指南》](https://github.com/eternity4719/HowToLiveBetter)管**个人的账**（寿命、金钱、时间、人身自由），本书管**关系的账**。它的条目结构、证据分级 A/B/C、反幻觉的 skill 设计、检索页与构建工具的形态是本书的方法论范本；本书的口径、成本维度（难受/时间/毅力）和全部内容为关系领域重新定义。两本书内容各自独立，交叉引用均为指向。

## 核实

每写一条，先检索原始文献再写正文，过程和未核到的细节登记在 [docs/核实记录/](docs/核实记录/)。三轮核实均由 AI 完成（研究 agent 检索原文/官方页并核对摘要），发布路线和人工复核要求见各批文件末尾的清单。

## 自己跑一份

多数人用不着部署：开 GitHub Pages 就有检索页，要离线就构建单文件版。本地完整体验：

```bash
git clone https://github.com/yuzhang-zhong/HowToGetAlong.git
cd HowToGetAlong
python -m http.server 8000     # 在线检索页（http://localhost:8000/）
node tools/offline/build.mjs   # 离线单文件 dist/HowToGetAlong.html
node tools/build-prompt-only.mjs # 生成纯提示词精选版
node tools/validate.mjs        # 条目格式校验（CI 也跑这一步）
```
