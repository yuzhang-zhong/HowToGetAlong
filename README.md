<h1 align="center">高性价比关系指南</h1>

<p align="center">关系里那些难开口、想不通、容易受伤的时刻，翻一条能用的建议。</p>

朋友报喜时怎么回应？拒绝的话怎么说出口？争吵升温时怎样停下来？这本指南也谈交朋友、职场和家人、性与亲密，以及危险关系里的求助和自我保护。

全书 18 章、274 条建议。每条都写清要花多少难受、时间和毅力，可能换来什么，以及证据等级和出处。翻到正遇上的问题，挑一条试试就好。

## 在线检索

仓库根目录的 `index.html` 可以按关键词、章节、证据等级、收益量级、口径和三项成本筛选。它还标出性价比档与安全章优先级；点「第 X 章第 Y 条」可以预览关联条目。检索内容直接来自 `book/`，改完正文后重新构建即可同步。

- **在线使用**：在仓库 Settings → Pages → Deploy from a branch，选择 `main` 和 `/`。
- **本地使用**：在仓库目录运行 `python -m http.server 8000`，再打开 `http://localhost:8000/`。浏览器直接打开 HTML 文件时无法读取本地数据，可使用下面的离线版。
- **离线单文件**：运行 `node tools/offline/build.mjs`，生成 `dist/HowToGetAlong.html`。书和检索页都在里面，双击即可打开，也可以通过微信发送。

术语可以查[术语表](docs/术语表.md)。

## 让 AI 照书回答

仓库附有中文 skill：[skills/relationship-guide](skills/relationship-guide/)。安装后，直接问「朋友借钱不还怎么开口」「吵架吵到失控怎么办」「他这样算不算家暴」。它会先检索相关条目，再按书中的顺序回答并注明章节和条目；查不到时会直接说明。遇到正在发生的家暴、自杀念头或未成年人受侵害，先提供资源和眼下能做的一步。

- **Claude Code / Codex**：安装方法见 [skill 说明](skills/relationship-guide/README.md)。
- **对话式助手（如 Muse）**：把 `book/` 各章作为知识库上传，再把 `SKILL.md` 全文贴进系统提示词。
- **只能填写系统提示词的助手**：粘贴[纯提示词精选版](skills/relationship-guide/PROMPT-ONLY.md)。里面收录 30 条常用建议和安全章全部 30 条；其他问题会明确说明未收录。

## 每条建议长这样

```markdown
### 1. 吵到心跳加速、说不出整句话时，叫暂停并约好半小时后回来
<!-- 成本标签: 难受=少 时间=少 毅力=些 收益=大 口径=关系质量 -->
- 成本：硬着头皮说「我需要停一下」。
- 说人话：吵到身体接管嘴巴的时候，心跳加快、耳朵像关上了，只剩下想赢……
- 收益：夫妻冲突对话研究发现，生理唤起水平与婚姻不满相关……
- 证据等级：B
- 来源：Levenson RW, Gottman JM (1983). Marital Interaction. JPSP. https://doi.org/10.1037/0022-3514.45.3.587
- 备注：暂停前约好回来谈的时间，避免对方把暂停理解成冷处理……
```

## 证据分级

| 等级 | 含义 |
| --- | --- |
| A | 有可查的具体数字，来源为荟萃分析、大型队列或随机对照试验（RCT）；法律条目引用法条或官方文件原文。 |
| B | 有研究支持，但没有确切数字；或依据来自小样本、单项研究、观察性或相关性设计。 |
| C | 来自作者经验或公认做法，缺少直接研究文献。 |

274 条中 A 级 126 条、B 级 122 条、C 级 26 条。关系研究里能给出清晰数字的证据较少，因此分级按证据本身来定：观察性研究没有确切数字或交叉验证时最高为 B；流行说法追不到一手文献时标 C；复制失败的说法（如「手机摆在桌上就毁掉对话」）会降级并注明。

条目写法、口径、成本标签、性价比档算法（`index.html` 中的 `COST_W` / `tierRule`）和排序规则，见[写作规范](docs/写作规范.md)。有争议的条目会列出反方证据；尚未核实的会标注「待人工复核」。

## 和《高性价比人生指南》

[《高性价比人生指南》](https://github.com/eternity4719/HowToLiveBetter)讨论寿命、金钱、时间和人身自由；本书把它的条目结构、A/B/C 证据分级、反幻觉 skill、检索页和构建工具，用在了人际关系主题上。成本维度调整为难受、时间和毅力，内容按关系领域重新撰写。两本书各自维护，交叉引用用来指路。

## 文献核实

新条目先检索原始论文或官方文件，再写正文；核实过程和没能确认的细节都登记在[核实记录](docs/核实记录/)中。现有条目完成了三轮 AI 检索，人工复核安排见各批文件末尾的清单。

## 自己跑一份

开 GitHub Pages 就能使用检索页；需要离线时可以构建单文件版。本地完整体验：

```bash
git clone https://github.com/yuzhang-zhong/HowToGetAlong.git
cd HowToGetAlong
python -m http.server 8000        # 在线检索页：http://localhost:8000/
node tools/offline/build.mjs      # 离线单文件：dist/HowToGetAlong.html
node tools/build-prompt-only.mjs  # 生成纯提示词精选版
node tools/validate.mjs           # 校验条目格式，CI 也会运行
```
